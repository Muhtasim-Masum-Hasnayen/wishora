## ✨ Overview

**Wishora** is a responsive birthday website builder designed to turn heartfelt wishes into personalized digital experiences.

Instead of sending an ordinary birthday message, users can customize a birthday page with a relationship category, recipient details, a personal message, a visual theme, and other thoughtful details. They can preview their creation and generate a shareable link to make someone's special day more memorable.

The goal is simple: make digital birthday wishes feel more personal, creative, and meaningful.

## 🚀 Key Features

- 🎁 **Relationship-Based Personalization** — Create birthday wishes for friends, partners, siblings, and spouses.
- 🎨 **Multiple Visual Themes** — Choose from six themes: Midnight Blue, Petal Bloom, Velvet Love, Golden Hour, Lavender Sky, and After Hours.
- ✍️ **Personalized Messages** — Add the recipient's name, sender's name, birthday date, personal message, and a memorable note.
- 🖼️ **Photo Customization** — Add a publicly accessible image URL.
- 👀 **Live Preview** — Preview the birthday experience before sharing.
- 💌 **Surprise Reveal** — Enable a special reveal experience for the recipient.
- 🔗 **Shareable Birthday Pages** — Generate a URL containing the birthday-page data.
- 💾 **Draft Persistence** — Save draft data locally in the browser.
- 📄 **Downloadable Wishes** — Download the birthday wish as a text file.
- 📱 **Responsive Interface** — Designed for desktop, tablet, and mobile screens.

## ⚙️ Run Locally

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Muhtasim-Masum-Hasnayen/wishora.git
```

### 2. Open the project directory

```bash
cd wishora
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```

To create a production build, run:

```bash
npm run build
```

## 🚀 Deployment

Wishora is deployed on **Vercel**.

To deploy your own version:

1. Fork or import the GitHub repository.
2. Sign in to Vercel using your GitHub account.
3. Import the `wishora` repository as a new project.
4. Keep the detected Next.js framework settings.
5. Click **Deploy**.

Future commits pushed to the connected production branch can trigger automatic deployments.

## 🔒 Privacy Notes

- Drafts are stored in the browser's local storage.
- Shareable URLs contain encoded birthday-page data.
- Anyone with access to a shared URL may be able to read the information embedded in it.
- Avoid including passwords, sensitive personal information, or private photos in shareable pages.
- Photo customization currently uses a public image URL rather than direct file uploads.
